## 继续补齐的源码

- 资料页：新增“默认展示共同群组”，默认关闭。实验标签页优先共同群组并保留手动选择；未开启标签页的经典入口保留返回完整资料的导航。首次未缓存资料和第三栏仍需实机核验。
- 字体：保留同时应用，并新增仅界面／仅消息；从字体解析和缓存层区分，覆盖正文、输入、媒体说明及富文本。代码、图标不改为正文字体。修改需重启；中文回退仍按 Qt 应用级策略处理。
- 跨端备份：根结构 `version`、`createdAt`、`values` 与 iOS 一致；六类别、106 个允许字段、2 MB 限制；55 个共享字段可映射。支持预览前后值、类别恢复／重置、账号隔离和过期预览拒绝。无法应用的值保留回传，未变的桌面默认值不会覆盖原值；修改可映射设置后导出反映新值。完整桌面备份和云备份格式仍各自保留。
- 隐私数据：过滤规则、隐藏发送者及会话覆盖属于用户选中的备份类别；登录凭据、API 凭据、服务密钥、聊天数据库与字体文件不进入跨端文件。对话覆盖只应用当前账号，保留其他账号的备份记录。
- 诊断：在媒体响应位置计量普通及流式下载、CDN、网页文件及 HTTP；不重复计入缓存读取，不计字体下载。每个已登录账号的会话单独计量，退出该会话清除；最近三秒平均速率用 100 ms 固定桶计算。后台测试与 iOS 相同的 100 条合成消息，仅测试时清除范围，旧任务取消，关闭页面不回写结果。结果不是帧率或固定加速倍数。

新增的 C++ 备份用例覆盖类别边界、字符串 ID 精度、敏感键排除、布尔／整数类型、范围、日期版本及 TTC 字体面选择。按用户要求未运行这些用例；仅执行源码与格式静态检查。媒体实验、菜单拖拽、未映射的通知／媒体／字体设置及全部运行验收仍未完成。

## 最新继续修复与构建启动

菜单排序补上拖拽手柄及靠近边缘时自动滚动，保留上下按钮，保存前不修改持久设置。共同群组默认入口改为一次性导航标记，经典资料页及第三栏在取得共同群组数据后进入列表；用户交互、超过四秒或返回完整资料时不再自动跳转。

补上按聊天防撤回、独立的自动删除／阅后即焚保留选项。全局 Ayu 保存策略沿用原行为；单聊天保护及新开关可独立工作。媒体保留同时解除本地销毁计时，避免已到期计时器重复处理。

通知增加置顶及提及／回复的默认、静默、关闭策略，以及聊天菜单中的覆盖入口。静默仍尊重原生静音和通知资格。跨端例外按 iOS 通知扩展实际使用的普通群组裸 ID 交换；频道例外不能假装与手机的 chat_id 相同。

字体备份补上六个关联字段，作为同一组预览和应用；已安装的目录字体和导入字体 SHA-256／字体面可映射。文件不进入备份，缺失文件、Apple 字体设计及无法表达的独立组合保留原数据并提示。

媒体实验增加滚动方向内的有限候选、合并调度、原生自动下载权限、视频前缀预取、最多三个延迟释放项、每会话最多两个自动播放视频、中心区域优先、后台及省电暂停和短时播放器保留。MTP 每数据中心最多同时启动两个自动任务，流播放期间限制为一个；手动下载有首次请求机会。最高／最低全局画质沿用原生选择路径，单视频手动选择优先。该实现是 Qt 引擎对应策略，并不声称与 iOS 的 HLS、系统内存警告和 gallery lease 完全相同。

已开始 arm64 Release 的语言／样式生成与 test_nagram 编译；当前不是安装包完成状态。最初命令发现系统 xcode-select 指向 CommandLineTools，重试仅为构建设置 DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer，没有修改系统全局配置。
