已执行 34 组功能回归，规则交换／匹配／Foundation 正则检查，以及附带的 7 条规则导入和回读。92 个字体文件在 macOS Qt 中通过大小、SHA-256 和实际加载检查，并渲染了字体预览。新版安装后的界面操作、真实翻译后端和新增功能的 Windows／Linux 运行验收尚未完成。

原版 7.3.1 跨平台构建使用冻结源码继续执行，新版本工作区不会被旧版发布程序加入安装包。

2026-10-11 追加：共享布尔绑定扩充至 27 项；赞助、计数器、快捷分享、推荐频道、回复、尾巴及资料 ID 入口合并，立即通知纳入延迟选择器。后续完整应用构建及安装包均使用 Release。旧 Windows 构建发现服务消息的未使用变量触发 `/WX`，已移除；旧 Intel runner 失联，新的 Intel 构建提前保存依赖缓存并降低应用编译并发。

Windows 字体路径增加 WOFF／WOFF2 原生解包，保留原始下载哈希校验及解包大小上限。全平台 Release 工作流增加 92 个真实字体的下载和 Qt 加载探针；尚未执行的新平台检查仍标为待验收。

本轮新增验证：5 组独立 Release 专项测试通过，附件 7 条规则导入回读通过；92 个字体再次在 Release Qt 中通过实际加载。64 个改动生产编译单元的定向编译通过。完整应用及各平台运行验收仍单独记录，不能由这些测试替代。

最新界面要求：主入口及页面标题统一为“Regram 设置”／“Regram Settings”，直接进入的结构及已有功能保持一致。
