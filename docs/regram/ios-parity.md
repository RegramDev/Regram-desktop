本轮 33 组功能回归、5 组专项 Release 测试和 92 份 macOS 字体校验通过；72 个受影响生产编译单元通过实际 Release 参数检查。旧基线的 34 组记录属于历史验收，不叠加到本轮数量中。

正式包的私有真实账号副本验证了 Regram 设置入口和标题、旧说明移除、无 Yandex 的来源列表、置顶下方整聊翻译栏、过滤器及输入设置、菜单拖拽和取消恢复。频道和群聊接受滚动输入后保持运行；这不能证明帧率或偶发卡顿已解决。格式面板自动化受焦点和快捷键影响，未取得可靠结果；不把这次尝试记为功能通过。消息右键操作、真实译文替换和富文本发送仍需专项运行验收。

整体仍为 `complete:false`。跨端备份采用相同的六类别和 106 字段允许列表，其中 72 项有桌面绑定，其余值保留回传并提示；文件不携带凭据、账号会话、聊天数据库或字体。媒体实验采用 Qt 的候选、缓存和播放器调度，不能宣称与 iOS HLS、内存警告和 gallery lease 相同。移动端 APNs、秘密聊天和底部导航属于引擎差异，不能用同名开关假装实现。

消息过滤的公开交换格式和使用说明见 [message-filters.md](message-filters.md)。旧 Desktop v1/v2 仅迁移本机存储，未知会话及话题保持停用。代码修改过程见 [源码修复记录](source-fixes-2026-10-12.md)。账号副本、截图和运行日志保存在忽略的私有目录，未加入源码和安装包。
