# Nagram 最新功能接入与性能

核对版本：[Nagram-Qt main `5d0222ca152396aa213f3455528ce09c544cce30`](https://github.com/NextAlone/Nagram-Qt/tree/5d0222ca152396aa213f3455528ce09c544cce30)，2026-10-10。Regram 继续使用 Telegram Desktop 7.3.0、Qt 6.11.2 和原版 Qt 界面，最低 macOS 12；不恢复 Liquid Glass。

对照当前源码补入聊天清理、免打扰时段及例外、账户关键词通知、按聊天选择发送前翻译语言与发送预览、Markdown 复制、已读／反应信息置顶、未知注册时间的明确估算、最近在线时间分级颜色，以及转发消息和相册的本地预览修复。发送前翻译在普通聊天和话题聊天两处接入；消息菜单顺序在两种菜单中接入；通知仍经过原有隐私、账户和静音判断。

原有 Nagram／AyuGram 功能、Regram iOS 过滤、加密保留库、品牌与人物图标保留。注册选项由 201 增至 206，三语资源检查涵盖 828 个扩展英文键及中文后备键。设置中新增外观→免打扰时段、高级→关键词通知、聊天→聊天清理、翻译→发送前翻译、消息显示→已读／反应信息置顶；复制 Markdown 是消息菜单可见性选项，默认关闭。注册时间估算与最近在线颜色仍由原有显示选项控制。

静态接入检查见 [nagram-hook-audit.json](nagram-hook-audit.json)：参考源码中 219 个命名消费者，211 个直接接入，设置入口经 Regram 包装接入，7 个源项目版本／发布通道入口沿用 Regram 策略。Nagram 的图标、应用身份、版本修订号和更新下载源不用于 Regram；Regram 未配置独立的签名更新服务，自动更新继续关闭。这份检查证明源码调用存在，不等同于全部功能的运行验收。

性能修改：重复读取结构化配置时复用验证结果，但每次仍比较底层当前值，保留外部修改、配置导入、无效值诊断和修复后的行为；过滤规则编译及解析使用有上限的缓存，按原始配置区分；隐藏消息查找复用集合；关闭的过滤规则跳过正文拼接；同一事件循环内的多个显示设置变更合并成一次消息视图刷新，排队回调受会话寿命保护。

Debug arm64 同一组基准：32 条规则，配置读取 10,000 次从 13,447.5 ms 降至 5.57 ms；处理 1,000 条消息从 1,919.0 ms 降至 41.78 ms。基准程序在 `regram/nagram/tests/test_performance.cpp`，用 `REGRAM_BENCHMARK=1 out/nagram-tests/Debug/test_nagram` 运行。记录见 [nagram-performance.json](nagram-performance.json)。这是指定 CPU 路径的测量，不能外推为界面帧率或整应用加速倍数；空闲采样没有捕获到消息滚动。

32 组模型、预算、设置交换与语言／资源检查通过。包含跨午夜和周末时段、通知例外、关键词匹配、发送前翻译语言／容量／序列化、Markdown 实体范围与转义、聊天清理排除规则、注册时间边界、配置缓存失效与正则缓存淘汰后重建。应用内隔离写入／重启读取两轮均 PASS、退出码 0，确认 206 项注册、原版 Qt、品牌与图标、历史／配置兼容、Markdown 菜单、免打扰／关键词通知决策、消息投影缓存失效和三个显示选项只触发一次消息重建。新增弹层逐一打开并截图。普通启动入口已恢复 no-op，最终 Debug 构建通过。

真实外部翻译／转写、媒体及网络请求、系统通知投递、Windows／Linux、macOS 12 实机仍需要各自验收；这次记录不将 M0～M8 的未验收条目自动标记为完成。


用户报告所有界面卡顿，因此追加公共 UI 绘制优化。控件级计时确认 `Ui::LayerStackWidget::BackgroundWidget` 是设置页的主要绘制成本；现在按 Qt 自身缓存的不透明子控件区域跳过背后的重复背景混合，不改布局、圆角、阴影、颜色或缓存动画。修改保存在固定基线的 `lib_ui.patch`，补丁预检与重复安装验证通过。

同一 800×632 逻辑尺寸、DPR 2、每页 120 次全窗绘制的对照：背景单次平均 12.38→8.26 ms；设置首页中位 19.46→15.83 ms，p95 20.34→16.24 ms；外观页中位 22.81→18.88 ms，p95 25.28→21.08 ms；聊天页 3.92→3.95 ms，保持相同量级。标题区域截图像素完全一致，面板整体 RGB 平均差约 0.019，最大差 3，肉眼核对原版 Qt 外观一致。这是离屏 QWidget::render 的 CPU 成本，不能等同真实屏幕 FPS、合成延迟或全部真实账号场景已无卡顿。
