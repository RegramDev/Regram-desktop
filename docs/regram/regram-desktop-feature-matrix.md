# Regram Desktop 功能移植矩阵

计划日期：2026-10-03。需求基准：[Regram iOS 已加入功能](features.md)；执行顺序、架构、平台与验收流程见[Desktop 实施计划](regram-desktop-plan.md)。

目标是交付所有适用于桌面的现有功能。功能编号用于任务、提交和验收记录；表中的阶段是计划安排，**所有条目目前均未完成 Desktop 实现或验收**。“继承”也需要验证，不能仅凭上游有类似名称就标记完成。

| 处理方式 | 含义 |
| --- | --- |
| 移植 | 用 Desktop 的 C++／Qt 代码实现已有产品行为 |
| 适配 | 保留功能目的，调整桌面交互、平台接口或存储方式 |
| 继承并补齐 | 从上游已有能力出发，逐项验收；缺少的部分仍在移植范围内 |
| 排除 | 没有对应桌面路径、依赖无法提供的服务端权限，或 iOS 已移除／未完成；见文末 |

矩阵按初始基线 `tdesktop v7.2.9` 编写。对上游能力的确认来自官方源码与发布记录，实际运行效果仍需在 M0 建立基线。所有“开关”均要求保存、恢复默认值、说明作用范围；“不支持”的平台应说明原因，不提供无效开关。

**A. 消息过滤与隐藏用户**

| ID | 功能 | 处理／阶段 | 完成标准 |
| --- | --- | --- | --- |
| RD-F01 | 普通关键词过滤 | 移植／M1 | 收到的文本按不区分大小写的子串匹配；自己发送的消息不误隐藏 |
| RD-F02 | 正则过滤 | 移植／M1 | 校验无效表达式；有执行预算；iOS ICU 规则的兼容性有明确测试和提示 |
| RD-F03 | 规则增删改、类型切换 | 移植／M1 | 修改保留稳定 ID，立即刷新相关窗口，切换类型时重新校验 |
| RD-F04 | 所有对话／指定对话范围 | 移植／M1 | 用户、群组、频道可选；会话 ID 不混淆账户或类型 |
| RD-F05 | 单会话停用过滤 | 移植／M1 | 从资料页切换，只停用该会话的关键词／正则规则 |
| RD-F06 | 消息／选中文字快捷添加 | 适配／M1 | 右键添加、复制并添加、重复提示均可用 |
| RD-F07 | JSON 导出与文件导入 | 移植／M1 | 合并不覆盖；保留规则范围；导入预览及错误提示；支持现有 iOS 格式转换 |
| RD-F08 | 聊天附件中的规则快捷导入 | 适配／M1 | 识别规则文件，由用户触发导入；收到文件不自动执行 |
| RD-F09 | 隐藏用户／机器人 | 移植／M1 | 在其出现的不同会话中一致隐藏，自己不被加入隐藏名单 |
| RD-F10 | 隐藏用户管理 | 适配／M1 | 列表、打开资料、解除隐藏；桌面按钮／右键替代左滑 |

| RD-F12 | 缓存与即时刷新 | 移植／M1 | 编辑消息、改规则、切换账户后正确失效；缓存有界；旧后台任务不覆盖新规则 |
