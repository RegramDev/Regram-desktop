2026-10-10。范围包括全部当前 Regram／Nagram／AyuGram 声明选项、高级字段、固定参考接入点，以及 M0～M8 的 129 项矩阵。本轮直接在当前工作区修改，没有提交或发布。

```sh
python3 Telegram/build/regram/check_features.py --output .cache/regram/full-feature-index.json
```

核对 207 个当前选项、117 个高级序列化字段、219 个固定参考接入点。没有注册选项重名、声明消费者／标题缺口、原有选项移除或接入点丢失。新增一项是高级备份快照。117 个字段包括嵌套与身份引用字段，不等于全部都适合导出；各集合互有重叠，不能相加当作独立功能总数。

这个检查证明声明、命名引用及接入位置存在，不证明每条条件、权限、网络行为或输出正确。机器可读记录包含每个选项的消费者、每个字段、每个接入点和下面每条矩阵标准：[feature-checks.json](feature-checks.json)。

## 尚存差异

源码检查仍未定位以下矩阵能力的独立实现：六档默认发送格式、单会话防撤回及集中列表、通话 Force TCP、完整 NSFW 网页入口、独立媒体加载试验开关。上游基础、全局防撤回、MTProto 连接偏好或季节装饰不能替代这些具体要求。

另外，保留库容量／期限、本地 Emoji Status、完整清除全部本地数据、失焦／空闲锁定语义和 M7 的媒体生命周期／预算仍有差异或验收缺口。它们不是由这次修复自动完成的。

macOS 12／Intel、Windows／Linux、真实外部翻译与转写、通话、设备拔插和系统通知投递仍需对应环境。本机编译和虚构账号无法代替这些结果。
